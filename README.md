## Background Work - React Concepts

### Components
Components are small, reusable pieces of a user interface. Each component controls how a part of the screen looks and behaves. They help keep code organized and easy to reuse.

### Props
Props are data passed from a parent component to a child component. They let components share information without changing it. Props are read-only and should not be modified by the child.

### State
State is data that belongs to a component and can change over time. When state changes, the component updates on the screen. State is used for things like user input or toggles.
